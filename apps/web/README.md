# apps/web — Aplicación web administrativa

Next.js 14 (App Router) + TypeScript + Tailwind CSS.

Uso: responsables SST, administradores de empresa, gerentes,
supervisores y auditores.

Incluye: dashboard gerencial, gestión de todos los módulos (trabajadores,
brigada, inspecciones, riesgos, accidentes, EPP, equipos, emergencias,
simulacros, contratistas, permisos, COPASST, auditorías, documentos,
indicadores, Seguridad IA, Centro de Comando, configuración) y el panel
de Super Admin.

**Estado**: pendiente de implementación (Fase 5 del roadmap, ver
`docs/ARCHITECTURE.md`).
