# packages/shared-types

Tipos y DTOs de TypeScript compartidos entre `apps/api`, `apps/web` y
`apps/mobile-pwa`, para que el contrato de datos de cada módulo de
negocio se defina una sola vez y no se duplique entre frontend y
backend.

**Estado**: pendiente de implementación (se puebla junto con la Fase 3,
a medida que se define el schema de cada módulo).
